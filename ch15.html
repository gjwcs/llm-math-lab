∑背后的公式
$$\operatorname{Var}(y \mid x) = \underbrace{\operatorname{Var}_{\boldsymbol{\theta}}\big(\mu_{\boldsymbol{\theta}}(x)\big)}_{\text{认知}} + \underbrace{\mathbb{E}_{\boldsymbol{\theta}}\big[\sigma_{\boldsymbol{\theta}}^2(x)\big]}_{\text{偶然}}$$
$$\underbrace{\mathbb{H}\big[\mathbb{E}_{\boldsymbol\theta}P(y\mid x,\boldsymbol\theta)\big]}_{\text{总熵}} = \underbrace{\mathbb{I}(y; \boldsymbol{\theta} \mid x)}_{\text{认知}} + \underbrace{\mathbb{E}_{\boldsymbol{\theta}}\mathbb{H}\big[P(y \mid x, \boldsymbol{\theta})\big]}_{\text{偶然}},\qquad \operatorname{SE}(x) = -\sum_{k} P(c_k \mid x) \ln P(c_k \mid x)$$

偶然不确定性来自数据本身的噪声，再多数据也消不掉；认知不确定性来自模型之间的分歧，只在缺少数据的地方变大。语义熵把意思相同的回答归入同一个簇 $c_k$，簇概率是簇内各回答概率之和。

∑背后的公式
$$\operatorname{ECE} = \sum_{b=1}^{B} \frac{|B_b|}{N} \big|\operatorname{acc}(B_b) - \operatorname{conf}(B_b)\big|,\qquad P_j(\beta)=\frac{e^{\beta z_j}}{\sum_k e^{\beta z_k}}$$
$$\mathcal{L}_{\text{CE}}(\beta) = -\beta z_{y^*} + \ln \sum_j e^{\beta z_j},\qquad \frac{\partial^2 \mathcal{L}_{\text{CE}}}{\partial \beta^2} = \operatorname{Var}_{j \sim P(\beta)}(z_j) > 0,\qquad \beta_{k+1}=\beta_k-\frac{\mathcal L'(\beta_k)}{\mathcal L''(\beta_k)}$$

对数配分函数的一阶导是期望 $\mathbb E_{P(\beta)}[z]$，二阶导是方差，所以 $\mathcal L_{\text{CE}}(\beta)$ 是严格凸函数，全局最优唯一，牛顿法几步就收敛。本实验中 $T^*$ 应当接近放大倍数 $s$，偏差来自有限样本。

%每次试验的实测覆盖率
绿带为理论区间 $[1-\alpha,\ 1-\alpha+\frac{1}{n+1}]$，深蓝线是累计平均。
C几道测试题的预测集合
∑背后的公式
$$\mathcal{C}(x_{\text{new}}) = \big\{ y : 1 - \hat p_{\theta}(y \mid x_{\text{new}}) \le \hat{q} \big\},\qquad \hat q=s_{(k)},\quad k=\lceil (n+1)(1-\alpha) \rceil$$
$$1 - \alpha \le \mathbb{P}\big( y_{\text{new}} \in \mathcal{C}(x_{\text{new}}) \big) = \frac{k}{n+1} \le 1 - \alpha + \frac{1}{n + 1}$$

证明只用到可交换性：测试分数 $s_{n+1}$ 在全部 $n+1$ 个分数中排第几名是等可能的，落进前 $k$ 名的概率恰为 $\frac{k}{n+1}$（罚分无并列时）。若 $k>n$（样本太少、$\alpha$ 太小），阈值取 $+\infty$，集合包含所有答案。保证是对“随机抽校准集 + 随机抽测试题”的平均而言，单次试验会围绕它波动。

🧪 试一试

  1. 书中例子：$\alpha=0.10$ 时 $k=\lceil 10\times0.9\rceil=9$，分数线 $\hat q=s_{(9)}=0.40$，只收 $\hat p\ge0.60$ 的病，诊断单是 $\{A,B\}$。
  2. 把 $\alpha$ 调到 0.05：$k=10>9$，阈值变成无穷大，四种病全收。9 个老病人撑不起 95% 的保证。
  3. 校准集取 $n=99$：$k=90$，理论覆盖率正好 $90/100$。点“重复 500 次”：累计平均覆盖率落在绿带附近，单次试验会上下波动，保证是对平均而言的。练习 15.2 可以把 $n$ 调到 19 看看 $k=18$。
  4. 换成“拿不准”的测试题，集合会自动变大；“很有把握”的题集合只剩 1 个答案。
