∑背后的公式
$$\mathbf{h} = \mathbf{W}_0 \mathbf{x} + \frac{\alpha}{r} \mathbf{B}\mathbf{A}\mathbf{x},\qquad \mathbf A\in\mathbb R^{r\times k},\ \mathbf B\in\mathbb R^{d\times r},\qquad \frac{\text{LoRA 参数量}}{\text{原参数量}} = \frac{r(d + k)}{d k}$$

先算 $\mathbf u=\mathbf A\mathbf x\in\mathbb R^r$ 再算 $\mathbf B\mathbf u$，计算量从 $dk$ 降到 $(d+k)r$。训练结束后合并 $\mathbf W_{\text{merged}}=\mathbf W_0+\frac{\alpha}{r}\mathbf B\mathbf A$，推理零额外延迟。$\alpha/r$ 让改变秩时不必重调学习率。

🧪 试一试

  1. 默认是书中的例子 $d=k=4096,\ r=8$：单个矩阵的参数从 1677 万降到 6.55 万，压缩比 $1/256\approx0.39\%$。
  2. LLaMA-7B 只在 $\mathbf W_q,\mathbf W_v$ 上挂 $r=8$ 的 LoRA：可训练参数约 420 万，只占全模型的 0.06%。
  3. 看显存账本：全量微调 7B 要一百多 GB，冻结权重后只剩 BF16 权重本身；再换成 4 比特（QLoRA）又砍掉四分之三。
  4. 切到 70B：全量微调要一千多 GB，QLoRA 可以塞进一张 48 GB 显卡（激活值另算）。

LoRA：$\mathbf A_0$ 随机，$\mathbf B_0=\mathbf 0$全零：$\mathbf A_0=\mathbf B_0=\mathbf 0$两者都随机

玩具问题：$\min_{\mathbf A,\mathbf B}\tfrac12\|\mathbf B\mathbf A-\Delta\mathbf W^*\|_F^2$，$d=k=16,\ r=4$，学习率 0.05。$\|\Delta\mathbf W_0\|_F$ 是第 0 步就泼到预训练模型上的“噪声”。

∑背后的公式
$$\min_{\operatorname{rank}(\mathbf{M}) \le r} \|\Delta \mathbf{W} - \mathbf{M}\|_F = \sqrt{\sum_{i = r+1}^{\min(d,k)} \sigma_i^2},\qquad \frac{\partial \mathcal{L}}{\partial \mathbf{B}} = \frac{\alpha}{r} \mathbf{G} \mathbf{A}^\top,\quad \frac{\partial \mathcal{L}}{\partial \mathbf{A}} = \frac{\alpha}{r} \mathbf{B}^\top \mathbf{G}$$

Eckart-Young-Mirsky 定理：截断 SVD 就是最优的秩 $r$ 近似。初始化时若 $\mathbf A_0=\mathbf B_0=\mathbf 0$，两个梯度都含有对方这个零因子，永远锁死在零点；LoRA 让 $\mathbf A_0$ 随机、$\mathbf B_0=\mathbf 0$，第 1 步 $\partial\mathcal L/\partial\mathbf B\neq\mathbf 0$ 先把 $\mathbf B$ 推开，第 2 步 $\mathbf A$ 也开始转动，同时保证第 0 步的输出与预训练模型完全一致。

🧪 试一试

  1. 默认谱衰减较快：$r=8$ 就捕获了绝大部分能量。把 $\gamma$ 调到 0（平坦谱），同样的 $r$ 误差立刻变大，低秩假设失效。
  2. 加大噪声：尾部奇异值被抬成一片“噪声地板”（Marchenko-Pastur 分布），截断反而起到去噪作用。
  3. 看热力图：秩 $r$ 近似保留了 $\Delta\mathbf W$ 的大块结构，残差只剩细碎纹理。
  4. 看初始化对比：全零那条线是水平的，两个梯度都是 0；两者都随机的那条起点更高，因为第 0 步就扰动了模型。

普通 LoRA 的一次更新会同时改变长度和角度；DoRA 只让 LoRA 负责方向，长度交给单独的标量 $m$（初始化为 $\|\mathbf w_0\|$）。拖动圆点改方向，滑块改长度，两者互不牵连。

∑背后的公式
$$q_i^{\text{NF4}} = \frac{1}{2}\left( \Phi^{-1}\!\left(\frac{i}{16}\right) + \Phi^{-1}\!\left(\frac{i+1}{16}\right) \right),\qquad \Phi^{-1}(p) = \sqrt{2}\,\operatorname{erf}^{-1}(2p - 1)$$
$$\mathbf{W}_{\text{DoRA}} = \mathbf{m} \odot \frac{\mathbf{W}_0 + \frac{\alpha}{r}\mathbf{B}\mathbf{A}}{\big\|\mathbf{W}_0 + \frac{\alpha}{r}\mathbf{B}\mathbf{A}\big\|_c},\qquad \mathbf m_0=\|\mathbf W_0\|_c$$

思路是让 16 个刻度在正态分布下等概率。书中公式取相邻分位点的中点，但两端 $\Phi^{-1}(0)=-\infty$；QLoRA 的实际实现用偏移 $0.9677$ 截断两端，正半轴取 8 个、负半轴取 7 个分位点，再加上精确的 0，最后除以最大值归一到 $[-1,1]$，本页的 NF4 刻度就是这样算出来的。双重量化把每块的 FP32 缩放常数再量化成 8 比特（每 256 块共用一个 FP32 常数），额外开销从每参数 0.5 比特降到约 0.127 比特。

🧪 试一试

  1. 默认块大小 64：NF4 的均方误差明显低于 INT4，刻度使用率也更均匀（熵更接近 4 比特）。
  2. 把块大小调到 4096：absmax 被极端值拉大，$w/c$ 挤向 0 附近，INT4 两端的刻度几乎没人用，误差差距进一步拉大。
  3. 把块大小调到 16：每块只有 16 个数，$w/c$ 不再像正态分布，INT4 甚至略胜 NF4；代价是缩放常数的开销翻 4 倍，达到每参数 2 比特。
  4. 块大小为 64 时勾选双重量化并切到 70B：缩放常数从约 4.3 GB 降到约 1.1 GB。
  5. 在 DoRA 图里把紫点沿圆弧拖动：只有方向在变；再拖动 $m$ 滑块：只有长度在变。普通 LoRA 做不到这样分开调。
