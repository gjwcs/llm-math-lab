模型已经吐出“我不知道”。书中 12.1 节的三条铁律：句尾“知道”后面，“我”45%、句号“。”40%；“知道我”后面“不”80%；“知道我不”后面“知道”95%。
每一步先把概率按温度变形 $p_i^{1/T}$ 再归一化（等价于打分除以 $T$），然后抽签；抽到句号“。”就结束，最多接 40 个词。

✎接龙结果
#1000 句里“我不知道”复读了几遍
Y两步树枝
∑背后的公式
$$P(y_1,\dots,y_L\mid x)=\prod_{t=1}^{L}P(y_t\mid x,y_1,\dots,y_{t-1}),\qquad y_t^*=\operatorname*{arg\,max}_{w}P(w\mid x,y^*_{1},\dots,y^*_{t-1})$$

贪心解码只看眼前这一步谁是第 1 名。自回归模型又会把自己吐出的字喂回去，一旦绕进“我 → 不 → 知道 → 我”的环路，而且重复越多“我”的概率越高（Holtzman 等人 2019 年观察到的正反馈），就再也出不来。给第 2 名一点被抽中的机会，句子就能体面地结束。

✎玩具语言模型续写
∑背后的公式
$$p_i(T) = \frac{\exp(z_i / T)}{\sum_{j=1}^{V} \exp(z_j / T)}$$
$$V^{(p)}：\text{按 } p_i(T) \text{ 从大到小累加，首次满足 } \textstyle\sum_{i \in V^{(p)}} p_i(T) \ge p \text{ 就关门}$$

$T\to0^+$ 时只剩最大的 $z_{i^*}$，退化为贪心解码；$T\to\infty$ 时 $p_i\to 1/V$，退化为闭眼瞎抓。Top-$K$ 固定保留 $K$ 个词；Top-$p$ 的候选池大小随语境自动伸缩：模型胸有成竹时只留一个词，面对开放问题时自动放宽。

右侧玩具模型是一个手写的二元语法表（约 40 个词），每个词只给少数几个合理后继打高分，其余词（包括“香蕉、齿轮”这类离谱词）统一给很低的分。它足以复现 Holtzman 等人发现的两种退化：贪心时陷入复读，高温时滑进长尾胡言乱语。

3一条偏好数据
提问 $x$：“有人摔倒了怎么办？”
$y_w$ 好回答赶紧扶起来问问有没有受伤。
$y_l$ 差回答在旁边看热闹。
整句对数概率（可拖动，也可在右侧曲面上拖点）：
参考模型 $\pi_{\text{ref}}$ 保持冻结，书中两条回答都是 0.10。初始时 $\pi_{\boldsymbol\theta}=\pi_{\text{ref}}$，隐式奖励相等，损失为 $\ln 2\approx0.693$；“书中训练后”把好回答设为 0.2718、差回答设为 0.0368，损失降到 0.127。
L损失与纠错权重
$-\ln\sigma(\beta u)$ 权重 $\sigma(-\beta u)$ 其他 $\beta$
∇损失曲面 $(\Delta_w,\Delta_l)$
等高线全是斜 45° 的直线：DPO 只关心差值 $u=\Delta_w-\Delta_l$，梯度永远沿 $(1,-1)$ 方向。
∑三行推导：奖励模型是怎么被消掉的
$$\mathcal{L}_{\text{DPO}}(\boldsymbol{\theta}) = -\mathbb{E}\Big[\ln \sigma\big(\beta\,\underbrace{\ln \tfrac{\pi_{\boldsymbol{\theta}}(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)}}_{\Delta_w} - \beta\,\underbrace{\ln \tfrac{\pi_{\boldsymbol{\theta}}(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}}_{\Delta_l}\big)\Big]$$
  1. 带 KL 约束的 RLHF 目标可以配凑成 $-\beta D_{\text{KL}}(\pi\,\|\,\pi^*)+\beta\ln Z(x)$，KL 非负，所以最优策略为 $\pi^*(y\mid x)=\frac{1}{Z(x)}\pi_{\text{ref}}(y\mid x)\exp\!\big(r(x,y)/\beta\big)$。
  2. 两边取对数移项：$r(x,y)=\beta\ln\frac{\pi^*(y\mid x)}{\pi_{\text{ref}}(y\mid x)}+\beta\ln Z(x)$。
  3. 代入 Bradley-Terry 概率 $\sigma\big(r(x,y_w)-r(x,y_l)\big)$，只与 $x$ 有关的 $\beta\ln Z(x)$ 一正一负抵消，得到上式。
$$\nabla_{\boldsymbol{\theta}} \mathcal{L}_{\text{DPO}} = -\beta\, \mathbb{E}\big[\sigma(\hat r_l-\hat r_w)\,\big(\nabla_{\boldsymbol{\theta}} \ln \pi_{\boldsymbol{\theta}}(y_w \mid x) - \nabla_{\boldsymbol{\theta}} \ln \pi_{\boldsymbol{\theta}}(y_l \mid x)\big)\big],\qquad \hat r=\beta\ln\tfrac{\pi_{\boldsymbol\theta}}{\pi_{\text{ref}}}$$

本实验把两条回答的对数概率 $\ln\pi_{\boldsymbol\theta}(y_w\mid x)$、$\ln\pi_{\boldsymbol\theta}(y_l\mid x)$ 当作两个自由参数，一步梯度下降就是：好回答加 $\eta\beta\sigma(-\beta u)$，坏回答减同样的量。

🧪 试一试

  1. 默认是书中 12.4 节的设定：$\beta=1$，$p_{\text{ref}}=p_{\boldsymbol\theta}=0.10$，损失 $\ln2\approx0.693$。点“书中训练后”：隐式奖励变成 $+1$ 与 $-1$，奖励差 2，损失 $\ln(1+e^{-2})\approx0.127$。

  4. 把两个 $\ln\pi_{\boldsymbol\theta}$ 同时减 1：两个概率都变小了，但差值不变，损失纹丝不动，这就是书中问 4 说的“好回答也被顺带拉下水”。
